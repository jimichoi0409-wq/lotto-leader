로또대장 개인정보처리방침

시행일: 2026년 10월 18일 · 운영자: 한지성

로또대장(Lotto Leader, 이하 "앱")은 회원가입 없이 무료로 이용하는 로또 번호 생성 앱입니다. 이 방침은 앱이 어떤 정보를 다루는지 설명합니다.

1. 앱이 직접 수집하는 개인정보

앱은 이름, 전화번호, 이메일 등 개인을 식별할 수 있는 정보를 수집하지 않습니다. 처음 실행할 때 닉네임만으로 간단히 가입합니다. 다음 정보는 사용자의 기기 안에만 저장되며 운영자에게 전송되지 않습니다.

  • 간단 가입 시 정한 닉네임과 가입일, 번호 추출 기록 (설정 → 탈퇴로 언제든 삭제)
  • 직접 입력한 당첨번호
  • 선택한 언어와 복권, 첫 실행 날짜
  • 당첨번호 데이터(앱 내장 및 자동 갱신분)

2. 광고 (Google AdMob)

앱은 무료 제공을 위해 Google AdMob 광고를 표시합니다. 이 과정에서 Google이 다음 정보를 수집할 수 있으며, 광고 제공·분석·부정 사용 방지에 쓰입니다. 전송 시 암호화됩니다.

  • IP 주소(대략적인 위치 추정에 사용될 수 있음)
  • 광고 ID 등 기기 식별자
  • 앱 실행, 탭, 광고 시청 등 사용 정보
  • 앱 성능·진단 정보

유럽경제지역·영국·스위스 등 동의가 필요한 지역에서는 처음 실행할 때 동의 여부를 묻고, 앱의 설정 → "광고 개인정보 설정"에서 언제든 바꿀 수 있습니다. 광고 ID는 기기 설정에서 재설정하거나 삭제할 수 있습니다. 자세한 내용은 Google이 파트너 앱의 정보를 사용하는 방법을 참고하세요.

3. 당첨번호 자동 갱신

앱은 최신 당첨번호를 GitHub Pages에 공개된 파일에서 내려받습니다. 이때 개인정보를 보내지 않지만, 접속한 IP 주소가 GitHub 서버 기록에 남을 수 있습니다(GitHub 개인정보 처리방침).

4. 아동

앱은 아동을 대상으로 하지 않습니다. 복권 구매는 각 나라의 법정 연령 이상만 가능합니다(한국 만 19세 이상).

5. 보관과 삭제

앱을 삭제하면 기기에 저장된 정보가 모두 지워집니다. 운영자가 별도로 보관하는 개인정보는 없습니다.

6. 방침 변경

이 방침이 바뀌면 이 페이지에 시행일과 함께 게시합니다.
